# blackday-docs

Пошаговые инструкции по сборке домашней инфраструктуры, устойчивой к нестабильному интернету: от рабочего места администратора и локального DNS до резервных каналов связи и автономных сервисов.

Инструкции пишутся по мере того, как каждый шаг реально выполняется и проверяется на живом железе. Ничего не публикуется «по памяти».

## Для кого это

Для тех, кто держит дома Linux-машины и хочет, чтобы они продолжали работать, когда интернет работает плохо или не работает вовсе. Предполагается знакомство с командной строкой, SSH и базовыми сетевыми понятиями.

## Порядок шагов

| Шаг | Что делаем | Статус |
|---|---|---|
| [00](steps/00-overview.md) | Общая архитектура и принципы | черновик |
| [10](steps/10-keeper.md) | Рабочее место администратора и хранилище секретов | проверено |
| [20](steps/20-pi-base.md) | Базовая настройка одноплатника: сеть, SSH, файрвол, время | проверено |
| 30 | Локальный DNS: Pi-hole + Unbound с устойчивым кэшем | в работе |
| 40 | Мониторинг качества канала | план |
| 50 | Внешний сервер: защита, обход блокировок, сервисы | план |
| 60 | Резервный канал и автоматическое переключение | план |
| 70 | Локальные зеркала, кэши и офлайн-знания | план |
| 80 | Связь без интернета (LoRa) | план |
| 90 | Полный туннель домашней сети во внешний сервер | план |

Шаги нумеруются с интервалом 10, чтобы между ними можно было вставлять новые, не переименовывая остальные.

## Готовые конфиги

В [snippets/](snippets/) лежат файлы конфигурации, на которые ссылаются шаги. Их можно копировать целиком, заменив значения-плейсхолдеры.

## Условные обозначения

Все адреса, домены и имена в тексте — примеры. Подставляй свои.

| В тексте | Что это |
|---|---|
| `192.0.2.0/24` | домашняя подсеть |
| `192.0.2.1` | роутер (шлюз) |
| `192.0.2.10` | одноплатник |
| `198.51.100.10` | внешний сервер (VPS) |
| `example.com` | твой домен |
| `keeper` | рабочее место администратора |
| `admin` | имя пользователя |
| `Region/City` | часовой пояс |

Диапазоны `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24` и домен `example.com` зарезервированы стандартами специально для документации, поэтому они гарантированно ничьи.

Правила оформления новых инструкций — в [CONVENTIONS.md](CONVENTIONS.md).

## Дисклеймер

Это заметки о собственной домашней сети, а не руководство по промышленной эксплуатации и не совет по безопасности для чужой инфраструктуры. Команды выполняются на твой страх и риск: часть из них необратимо уничтожает данные. Читай раздел целиком, прежде чем выполнять его команды.
