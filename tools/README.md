# tools

## leakcheck.py

Проверяет, что в публичный репозиторий не попали приватные данные.

```bash
python3 tools/leakcheck.py --staged   # то, что добавлено в индекс
python3 tools/leakcheck.py --all      # все отслеживаемые файлы
```

Что он ищет:

1. **IPv4-адреса.** Публичный адрес вне списка разрешённых — ошибка, коммит не пройдёт. Приватный адрес (`10.x`, `192.168.x`, `172.16–31.x`) — предупреждение: он не выдаёт тебя, но в документации лучше держать единый стиль с `192.0.2.x`. Легитимные исключения (публичные DNS-резолверы) перечислены в `tools/allowed-ips.txt`.

2. **Строки из личного списка `.leakcheck`.** Это твой домен, имя хостинг-провайдера, внешний IP, выбранные номера портов, имена хостов — всё, что нельзя публиковать, но что легко случайно вставить вместе с выводом команды.

## Файл .leakcheck

Лежит в корне репозитория, перечислен в `.gitignore` и **никогда не коммитится**: сам по себе он раскрывает ровно то, что мы прячем. Формат — по одному регулярному выражению в строке, регистр не важен.

Создай его после того, как появятся реальные значения:

```conf
# Домен и внешний сервер
mydomain\.example
203\.0\.113\.\d+

# Хостинг-провайдер
some-hosting-name

# Домашняя сеть
198\.51\.100\.\d+
```

Точки в IP и доменах экранируются: в регулярном выражении неэкранированная точка означает любой символ.

Поскольку файл локальный, в CI эта проверка не выполняется — там работает только проверка адресов. Для машин, с которых ты коммитишь, держи копию `.leakcheck` рядом с остальными конфигами в приватном репозитории.

## Установка хука

После клонирования репозитория на новую машину:

```bash
ln -sf ../../tools/pre-commit .git/hooks/pre-commit
```

Хук — символическая ссылка на файл внутри репозитория, поэтому обновляется вместе с ним. Папка `.git/hooks` не версионируется, так что ссылку нужно создавать на каждой машине заново.

## Проверка, что хук работает

```bash
# Подставь любой реальный публичный IP вместо ЗДЕСЬ_ПУБЛИЧНЫЙ_IP,
# например адрес своего сервера. В файл репозитория его писать не нужно —
# проверка выполняется во временном коммите, который тут же отменяется.
printf 'test %s\n' ЗДЕСЬ_ПУБЛИЧНЫЙ_IP > leaktest.md
git add leaktest.md
git commit -m "test"     # ожидается ОШИБКА на публичный адрес
git rm --cached leaktest.md
rm leaktest.md
```

Заодно проверь личный список: добавь в `.leakcheck` строку `secret-test-string`, положи её в тестовый файл и убедись, что коммит снова отклонён.
